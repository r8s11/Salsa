## Direction contract

THESIS: Salsa Segura is a listings publication and this is its desk. The surface leads on the work itself — unset entries and the week they are being set into. It refuses the category-default arrangement of a KPI stat-card grid above a recent-activity table, which pretends an evening review queue is enterprise analytics.

OWN-WORLD: Agate listings setting plus copy-desk proof marking. Dense rule-separated rows at listing scale, a hanging margin column carrying state as a proof mark, tabular lining numerals, no cards and no panels — rules and measures do the dividing. A closed state palette is law: one colour per state (unset, marked, set, killed, live-tonight), used nowhere else on the surface. Explicitly not broadsheet-editorial hairlines with italic display serif and tracked mono labels.

STORY: The operator sees how much is unset and what the week already looks like in one glance, believes the queue is finite and the calendar real, and decides the first entry without navigating anywhere.

FIRST VIEWPORT: A standing top rule carries the date and only the counts that represent work. Below it, two measures. Left, narrower: the galley — entries awaiting decision, each a listing row with its flyer at thumb size and its state in the hanging margin; the primary action sits in the first entry. Right, wider: the set column — the live week, day by day, agate, ruled, each entry pinned to its true position on a fixed seven-division measure. Host gets the same world in a single measure.

FORM: Grounded candidate 4 of seven derived from nightlife operations and its graphic traditions, assigned by the roll over my top-ranked Call Sheet. Raises taken from declined challengers: one propagation (a decision updates galley, column and counts as a single linked change); pinned to one axis (nothing floats free of the time axis); focus swells while the rest compresses (an entry expands in place to full working detail, never a separate review page); state is palette law; one measured grid. Kept from the competitive vertical-feed challenger: flyer-first single-entry triage with a persistent action rail, as the review reading inside the column rather than the shape of the dashboard.

MEMORABLE MOMENT: Set in place. Deciding an entry lifts it out of the galley and sets it into the column at its true date position, the column reflowing around it and the top-rule counts decrementing in the same propagation. No route change, no toast.

Unresolved: none blocking. Honest risk being managed during build — agate is small; listing scale governs rows only, while controls and decisions stay at full UI size and the state palette carries the reading load.
