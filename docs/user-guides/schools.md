# School owners and managers

Maintain your school listing, weekly timetable, private lessons, and prices. Last checked locally November 9, 2026; see [implementation status](improvements.md#verification-and-rollout) for rollout prerequisites.

## Get started

1. Find the school in [Schools](https://www.salsasegura.com/schools) and open its public page.
2. Sign in, then select **Claim this school**. Follow [listing access and teams](listing-access.md) to submit the claim and check its review status.
3. After approval, select **Open your workspace**, or select the school under **Your listings** on the [Host desk](https://www.salsasegura.com/host).
4. Check the sections available for your role.

| Role | School profile | Timetable, Privates, Prices | Team |
| --- | --- | --- | --- |
| Owner | Edit | Edit | Manage |
| Manager | Edit | Edit | Not available |
| Editor | Not available | Edit | Not available |

You can give front-desk staff Editor access to maintain offerings without giving them control of the school's identity or team. Use [the team instructions](listing-access.md#add-a-teammate) to add an existing account.

## Update the school profile

Owner or Manager access is required.

1. Select **Profile**.
2. Update **Description**, **Image link**, **Website**, **Instagram**, **Phone**, **Street address**, and **Postal code** as needed.
3. Use complete web addresses for Website and Image link. Image link expects a hosted photo URL, not a file upload; use an image you have the rights to publish.
4. Select **Save profile** and wait for **Saved.**
5. Open the school's public page to check the result and test its contact links.

The school's name, city, public page address, and listing status are managed by Salsa Segura. To correct the name, city, or page address, select **Request a change** on the Profile page, or open **Requests** and use **Ask for a change to name, city or page address**. The request shows **Waiting for review**, then **Change made** once approved; [follow a request](listing-access.md#follow-a-request). Contact Salsa Segura about listing status. Only Owners and Managers have **Requests**.

If your school is not in the directory, use **Not listed? Request a listing** at the bottom of [Schools](https://www.salsasegura.com/schools) before anything else.

## Maintain the weekly timetable

A timetable class repeats each week. It does **not** create a dated event on the main calendar, reserve a student's place, or process payment. Use the [organizer guide](organizers.md) for dated workshops, socials, and other events when you have organizer access.

### Add a class

1. Open **Timetable**.
2. Find the day and select **Add class**.
3. Complete the class fields:

   | Field | How to use it |
   | --- | --- |
   | Title | Use a clear class name, 2–120 characters. |
   | Day | Choose the weekday. You can change it from the day where you opened the form. |
   | Start time | Enter the school's local start time. |
   | Duration (minutes) | Enter a whole number from 15 to 480. |
   | Level | Choose All levels, Beginner, Improver, Intermediate, Advanced, or Open level. |
   | Dance style | Select a style when appropriate. If styles fail to load, you can save without one. |
   | Instructor | Type the teacher's name, or pick an artist from the search results to link their profile. See [Link teachers correctly](#link-teachers-correctly). |
   | Room | Add the room or studio when useful. |
   | Drop-in price (USD) | Enter dollars, such as `20` or `12.50`. Leave blank if there is no drop-in price to list. |
   | Status | Choose Active to show the class publicly, or Paused to keep it hidden. |
   | Notes | Add useful conditions, such as arrival instructions or registration requirements. |

4. Select **Add class** in the form.
5. Check the row in the timetable, then check **Weekly classes** on the public school page.

New entries start as Active, so check the status before saving if the class is not ready to be public.

### Change or stop a class

- **Edit** opens its form. Make the changes, then select **Save class**.
- **Pause** hides the class from the public page but keeps it in your workspace.
- **Resume** makes a paused class active again.
- **Delete** asks you to confirm **Delete class**. This permanently removes the entry; pause it if you might need it again.

The public timetable groups classes by day and sorts them by start time. Use Notes and your own contact channels for exceptions, and keep the recurring schedule current. There is no separate date-specific cancellation editor for a weekly timetable entry.

## List private lessons

1. Open **Privates**.
2. Select **Add private lesson**.
3. Enter a **Title**, **Price (USD)**, and **Duration (minutes)**. Titles use 2–120 characters; duration uses 15–480 whole minutes.
4. Add an **Instructor** (a plain name, or a linked artist chosen from the search results) and **Notes** if useful.
5. Choose **Active** or **Paused** under **Status**.
6. Select **Add private lesson** in the form.
7. Check **Private lessons** on the public school page.

Use **Edit** and **Save private lesson** to change an offer. Use the up/down arrow controls to choose the display order. **Pause** and **Resume** change public visibility; **Delete** and its confirmation permanently remove the offer.

This lists an offer and its price. It does not create bookable appointment slots or take a payment.

## Maintain prices and plans

1. Open **Prices**.
2. Select **Add price plan**.
3. Complete **Name**, **Type**, and **Price (USD)**.
4. Choose a type: **Drop-in**, **Class pack**, **Membership**, **Bootcamp**, or **Other**.
5. Use **Number of classes** when the plan includes a fixed number. Leave it blank if it is not counted.
6. Use **Valid for (days)** for an expiry period. Leave it blank if there is no expiry to list.
7. Add any conditions in **Notes**, then choose **Active** or **Paused**.
8. Select **Add price plan** and verify it under **Prices** on the public school page.

Enter prices as dollars, not cents. Optional class counts must be 1–1,000; optional validity periods must be 1–3,660 days. Plan names use 2–120 characters.

Use **Edit** and **Save price plan** for changes, and the arrows to reorder. Pause a plan to hide it without losing its details. A listed membership or class pack is information only; it does not automatically charge customers or create subscriptions.

## Link teachers correctly

The **Instructor** field in class and private-lesson forms works in one of three ways:

- **Plain name.** Type the teacher's name and save. Typing never creates an artist listing and never links one, even if the name matches an artist exactly.
- **Linked artist.** Type at least two characters, then pick the right artist from the search results; check the city shown under each name. The field then shows the artist with a **Linked artist** caption, and the public school page links the teacher to their artist page.
- **Unlink.** Select **Unlink** beside a linked artist. The name stays as plain text, which you can edit.

A link stays in place when you edit other fields and save. If a save reports that the linked artist is no longer active, unlink them and save again.

Only artists with a public Salsa Segura listing appear in the search. If the teacher has no listing, keep the plain name. [Artists and instructors](artists.md) explains the separate artist workspace.

## Check the public result

After important changes:

1. Open the school's public page using its existing link from the workspace.
2. Check **Weekly classes**, **Private lessons**, and **Prices**. Only active offerings should appear.
3. Confirm the day, start/end time, teacher name, price, and any conditions.
4. Test Website and Instagram links.
5. Check on a phone as well as a larger screen.

An empty offerings section can disappear entirely when all its entries are paused or removed. Upcoming calendar events linked to the school are separate from its weekly timetable.

## Troubleshooting

| Problem | What to check |
| --- | --- |
| Profile or Team is missing | Profile requires Owner/Manager access; Team requires Owner access. |
| A class is saved but not public | Check that it is Active and that you are viewing the correct school's public page. Refresh after saving. |
| An instructor is plain text, not a link | The entry has no linked artist. Open **Edit**, search for the artist in **Instructor**, pick them, and save. |
| A price is rejected | Use dollars with up to two decimal places, such as `12.50`, not `12,50` or descriptive text. |
| A status change fails | Open **Edit**, correct the highlighted fields, save, and retry. |
| An offering disappeared after Delete | Deletion is permanent. Use Pause for temporary changes in future. Contact Salsa Segura if you need assistance. |
| Weekly classes are not on the main calendar | Timetable entries and dated events are separate. Submit or create a dated event through the appropriate event workflow. |
