# Salsa Segura community event-coverage plan

**Status:** Proposed · **Date:** 2026-09-29 · **Primary goal:** Improve local event coverage

## Starting assumptions

Salsa Segura is a city-scoped salsa and bachata event guide for Boston and NYC. Public listings go through approval; dancers can suggest events and organizers can submit or manage them. The audience is pre-launch or small. Instagram, WhatsApp chats, and in-person events offer possible outreach, but there is no confirmed reliable community channel or established member base. Validate these assumptions before scaling the plan.

Start in **one city**, whichever has the strongest organizer relationships and the best chance of a useful weekly calendar. Do not split a small founding circle between Boston and NYC. Expand to the other city only after the first city's contribution loop works.

## Community identity and member value

**Identity:** Local dancers who make the scene easier for everyone to navigate.

- Dancers get a more reliable answer to “Where can I dance this week?” and recognition for useful tips, with permission.
- Organizers get accurate listings and a clear way to correct changes.
- Salsa Segura gets current event information from people close to the scene.

This is a **founder-led contributor circle**, not a new chat platform. Use direct outreach and existing channels; do not open a Discord or public group before members are already helping one another and someone can moderate it.

## First 30 days

1. **Recruit privately.** List 10 organizers and 10 dancers known through local events or existing contacts. Invite each individually to identify one upcoming night the calendar is missing, or one listing whose details have changed. Do not assume these contacts already exist.
2. **Use existing channels.** Collect leads through Instagram DMs, opt-in WhatsApp conversations, and in-person outreach. Point contributors to Salsa Segura's submission flow. Confirm event details with the organizer before publication; tips still pass through the existing approval process.
3. **Run one weekly ritual.** Publish a roundup of approved events for the chosen city. Ask “What’s missing or changed this week?” Reply personally to each useful tip, then tell the contributor when the listing is approved, corrected, or cannot be published.
4. **Recognize contributions carefully.** Credit contributors only with consent. Do not copy information from private chats into public listings without checking it with the organizer.

### First outreach message

> I’m building a more reliable [city] salsa and bachata calendar. Is there a night we’re missing or a listing that needs correcting? Send me the details and I’ll make sure it goes through review.

### Action today

Choose the first city, list 20 people to contact, and send five personal invitations. Record which obstacle each response reveals: missing relationships, unclear submissions, incomplete event details, or slow review.

## Weekly health check

Track:

- Approved events added from community tips in the chosen city.
- Number of people contributing again, not just once.
- Corrections resolved and time from submission to approval.
- Missing or stale listings found in the weekly roundup.

**Initial test target:** Five people contribute twice within 30 days. This is a hypothesis, not an established benchmark. If it happens, invite willing contributors into a small opt-in coordination chat. If it does not, improve the submission and feedback loop before adding another platform or expanding cities.

## Boundary with existing plans

This is an operational outreach plan for improving event coverage. It does not replace `docs/salsa_52week_plan.md` or change the product's event approval and organizer permissions.
